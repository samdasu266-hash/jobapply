# NECA 면접 준비 — 사용자 확인 맥락

## 최우선 정정 (2026-09-23)

- 입사 후 관심 팀·세부 업무는 아직 정하지 않았다.
- 먼저 익히고 싶은 것은 체계적 문헌고찰 실무와 신의료기술평가 제도·평가과정 전반이다.
- 선진입 의료기술 관리는 배워볼 수 있는 세부 업무 중 하나다. ‘가장 관심 있는 영역’, ‘희망 팀’, ‘첫 1년의 별도 핵심 목표’로 확대하지 않는다.
- 근거창출지원팀과의 경험 연결은 가능하지만 희망 배치로 해석하지 않는다.

## 제공된 마스터 노트의 사용 기준

사용자가 제공한 34개 주제의 면접 마스터 노트를 참고 맥락으로 사용한다. 기관 전체 HTA와 지원 직무의 안전성·유효성 평가를 구분하며, 학습은 근거 검토·평가 절차·선진입 과정관리·이해관계자 소통·연구관리의 다섯 축으로 정리한다.

학습 우선순위는 정의·연구원 역할·식약처와의 차이·SR·PICO·위원회·지원동기·실제 연구역량을 먼저, 제도별 비교·상황 질문·윤리·대표 경험을 다음으로 둔다. 조직·전략·인재상은 보조 학습, 세부 연혁·전문가 현재 인원·CI는 참고로 둔다.

노트 자체는 공식 원문 검증의 대체물이 아니다. A to Z의 과거 인원·기간과 현행 규정은 구분한다. 현재 조직·위원 인원·법정 기간을 새로 추가하거나 변경할 때는 공식 원문과 날짜를 확인한다. 전략목표의 공개값과 지표 정의·산식, 면접관 구성에 대한 가설도 구분한다.

## 경험 표현의 경계

- CP는 33종·세부유형 77개, 담당 시작은 2024년 1월이다.
- CP 월보고 15시간→3시간과 협진 1차 자료 작성 4시간 이상→약 1분은 서로 다른 사례다. 후자는 회신 대기·최종 보고 전체 시간이 아니다.
- FMEA RPN 감소를 실제 낙상 발생건수 감소로 말하지 않는다.
- SR 방법론 학습과 독립적인 SR 수행 경험 없음은 구분한다.
- SPSS 수업 실습과 현재 실무 숙련도를 구분한다. SAS 세부 절차와 영어 논문 검토 속도를 과장하지 않는다.
- 임상 기간은 2017.11~2020.04로 설명하고, 월수 표현은 증빙 확인 없이 단정하지 않는다.

## 화면 정리 원칙

개념→관련 질문→내 답변→최종 복습으로 연결한다. 반복 경고·개발 이력은 줄이고 출처·수치 범위·실제 수행 한계는 남긴다. 기존 카드·질문·경험 ID와 사용자 메모는 보존한다.
